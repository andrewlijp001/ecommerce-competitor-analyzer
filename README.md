# 🕵️‍♂️ 电商竞品分析雷达 (v2.0-local)

基于 **卖家精灵 MCP** 与 **大语言模型 (Agent)** 打造的纯净版自动化竞品分析工具。

> ⚠️ **v2.0 重大更新**：本项目已全面重构！废弃了繁琐的 Olostep 爬虫、外部 Gemini API 和 Google Sheets 授权，彻底转型为 **Agent-Native（AI 原生）** 架构。现在，只要你的 AI 客户端支持【卖家精灵 MCP】，即可实现“开箱即用、一键出报告”。

---

## 🌟 核心能力

输入竞品 ASIN，AI 将自动调用卖家精灵数据库，为你产出一份结构化的「4维度竞品拆解报告」：

1. **💰 市场与定价 (The Pulse)**：销量预估、价格带、BSR 排名、利润分析。
2. **🚦 流量结构 (The Traffic)**：核心流量词反查（它吃的是什么词？）。
3. **🗣️ 评论与痛点 (The Voice)**：好评卖点归纳，差评致命伤（退货根因）精准提取。
4. **💡 差异化破局 (The Wedge)**：基于竞品痛点，直接给出产品改进和运营超越的战略建议。

支持单点深入分析，也支持批量 ASIN 对比（自动生成横向对比 CSV 矩阵）。

---

## ⚙️ 安装与配置

极简配置，告别 API 焦虑：

### 1. 克隆项目
```bash
git clone https://github.com/buluslan/ecommerce-competitor-analyzer.git
cd ecommerce-competitor-analyzer
```

### 2. 挂载到你的 AI 客户端
将本目录作为 Skill 挂载到支持的客户端（如 Claude Code, Antigravity 等）。

### 3. 配置卖家精灵 MCP（核心）
确保你的 AI 客户端已经配置好了 **卖家精灵 MCP 服务**（需要在卖家精灵官网获取 Secret Key，配置在 AI 客户端自身的 `mcp_config.json` 或设置面板中）。

*不需要修改本项目中的 `.env` 文件。*

---

## 🎮 使用方法

在对话框中，直接下达自然语言指令即可：

### 单个竞品深度拆解
```text
用竞品分析技能，帮我深度分析一下这个亚马逊产品：B0C4YT8S6H
```

### 多个竞品批量对比
```text
我打算做空气炸锅，帮我分析这 3 个竞品：B08N5WRQ1Y, B0CLFH7CCV, B0D123XYZ。请生成详细分析报告，并输出对比表格。
```

---

## 📁 产出物说明

分析完成后，Agent 会在本地自动生成以下文件：

- `reports/竞品分析-<ASIN>-<日期>.md`：单品深度拆解报告，可直接发给老板或研发团队。
- `output/竞品对比矩阵-<日期>.csv`：（仅在分析多个 ASIN 时生成）核心指标的横向对比表格。
